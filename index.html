1. Fundamentos de las Distribuciones

Binomial (Discreta)

Modela el número de éxitos en \(n\) ensayos independientes, donde cada ensayo tiene una probabilidad de éxito \(p\).

$$P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$$

Poisson (Discreta)

Modela la cantidad de eventos que ocurren en un intervalo de tiempo o espacio, dada una tasa promedio \(\lambda\).

$$P(X=k) = \frac{e^{-\lambda} \lambda^k}{k!}$$

Normal (Continua)

La "Campana de Gauss". Es la distribución más importante de la estadística debido al Teorema del Límite Central.

$$f(x) = \frac{1}{\sigma \sqrt{2\pi}} e^{-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2}$$

3. Calculadora de Probabilidades en R

En R, las probabilidades acumuladas \(\le\) se calculan con el prefijo p. Para obtener intervalos o colas derechas, utilizamos propiedades básicas de la probabilidad complementaria.

probabilidades_R_ejemplos.R 
# =====================================================================
                  # CÁLCULO DE PROBABILIDADES EN R
                  # =====================================================================
                  
                  # --- 1. DISTRIBUCIÓN BINOMIAL (n = 20, p = 0.5) ---
                  n <- 20; p <- 0.5
                  
                  # Exacta P(X = 10)
                  dbinom(10, size = n, prob = p)
                
                # Cola Izquierda P(X <= 10)
                  pbinom(10, size = n, prob = p)
                
                # Cola Derecha P(X >= 10)  =>  1 - P(X <= 9)
                  1 - pbinom(9, size = n, prob = p)
                
                # Intervalo P(5 <= X <= 15) => P(X <= 15) - P(X <= 4)
                  pbinom(15, size = n, prob = p) - pbinom(4, size = n, prob = p)
                
                
                # --- 2. DISTRIBUCIÓN NORMAL (mu = 0, sigma = 1) ---
                  mu <- 0; sigma <- 1
                  
                  # Cola Izquierda P(X <= 1.96)
                  pnorm(1.96, mean = mu, sd = sigma)
                
                # Cola Derecha P(X >= 1.96)
                  1 - pnorm(1.96, mean = mu, sd = sigma)
                # Alternativa elegante en R:
                  pnorm(1.96, mean = mu, sd = sigma, lower.tail = FALSE)
                
                # Intervalo P(-1 <= X <= 1) => P(X <= 1) - P(X <= -1)
                  pnorm(1, mean = mu, sd = sigma) - pnorm(-1, mean = mu, sd = sigma)
